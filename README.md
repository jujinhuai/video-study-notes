# video-study-notes

结合视频字幕与真实教学画面，将计算机、数学课程整理为中文 Word 学习笔记。适合 B 站多分P、上下集课程，以及用户提供的字幕、截图和本地材料。

这是供 Codex 使用的技能，`SKILL.md` 定义工作流程；它不是独立的视频下载器或一键转写软件。

## 能做什么

- **按知识关系整理**：串联定义、原理、推导和演示，合并重复解释，保留关键步骤、成立条件、代表例子与纠错。
- **核对公式和代码**：检查符号、维度、输入输出及关键行为，结合实际可取得的画面确认。
- **适量突出重点**：一般重点局部加粗，少数核心内容使用深蓝色加粗；不为标重点扩写课程。
- **分批制作并整合**：默认每批最多5个视频或分P，完成检查后交付；全部范围完成后自动生成按知识关系整合的总稿。只有一批时不重复生成。
- **保留来源**：记录链接、分P、必要时间定位，以及字幕和画面的实际覆盖范围。

## 使用前准备

1. 在支持本地技能的 Codex 环境中安装本技能。
2. 提供视频链接和要整理的范围，或直接提供字幕、截图等可分析材料。网页取材需要可用的浏览器连接；登录或验证由用户完成。
3. 生成 Word 时需具备 `documents` 技能、可用的 Python 文档依赖，以及 DOCX → PDF → 页面图片的渲染环境。本仓库不附带这些依赖；可使用 LibreOffice 和 Poppler，并根据运行环境确认工具路径。

## 安装与调用

### 安装

已能在技能列表中找到 `video-study-notes` 时，无需重复安装。

需要安装时，可向 Codex 发送以下请求：

```text
$skill-installer
请从 <技能仓库链接> 的仓库根目录安装技能，命名为 video-study-notes。
```

将 `<技能仓库链接>` 替换为实际仓库地址。

也可将仓库内容放入 Codex 当前支持的技能目录，使 `video-study-notes/SKILL.md` 与三个子目录保持同级。当前官方文档列出的个人目录为 `~/.agents/skills/video-study-notes/`，项目目录为 `.agents/skills/video-study-notes/`。未识别时重启 Codex，再检查技能列表。参见 [OpenAI 官方技能说明](https://learn.chatgpt.com/docs/build-skills)。

### 最简调用

```text
$video-study-notes
请整理以下视频：<视频链接>
范围：<分P范围或时间区间>
```

在支持技能选择器的界面中，也可以直接选中本技能后发送链接和范围。

### 按需指定偏好

在请求中补充即可，例如：

```text
整理程度：均衡精简，保留必要推导和代表例子。
保存位置：<输出目录>
```

也可以指定只处理某些分P或时间区间、已有基础、侧重内容，以及仅在聊天中输出。未指定时使用技能默认流程，不需要逐条重复规则。

## 会得到什么

- 默认交付真实的 `.docx`；主题名不超过10个字符，已有同名文件不擅自覆盖。
- 多批任务提供各批 Word 和最终总稿，**最终总稿是覆盖已完成范围的整合版本**。
- 内容包括必要的概念解释、公式、步骤、例子与来源；批次稿和总稿分别渲染并逐页检查。正文达到10页时加入可更新目录。
- 如有未覆盖的分P、看不清的画面或来源冲突，会明确说明，不宣称完整完成。

## 使用边界

- 不根据标题、简介或评论猜写知识点；只读字幕不等于完整观看视频。
- 不自动下载视频或字幕，也不自动安装下载、转写工具。保存或嵌入关键帧需有用户授权。
- 仅在避免误解或纠正已确认错误时作必要补充，并标明“补充说明”；默认不新增练习、自测或延伸课程。
- 材料不足时先处理可确认内容并说明缺口；必要时请求对应材料。分批与复用旨在减少重复工作，不保证绝不卡顿或固定的 token 节省比例。
