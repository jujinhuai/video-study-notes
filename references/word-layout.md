# 学习讲义默认样式

用户指定样式优先；否则使用下表，通过Word样式统一设置，不逐段任意改变字体与字号。

| 元素 | 默认排版 |
| --- | --- |
| 页面 | A4，四边页边距均为2.5厘米 |
| 正文 | 等线11磅，两端对齐，首行缩进2个汉字，1.5倍行距；段前0、段后6磅 |
| 文档标题 | 等线22磅，加粗、左对齐，无首行缩进，1.2倍行距；段前0、段后18磅 |
| 一级标题 | 等线16磅，加粗、左对齐，无首行缩进，1.2倍行距；段前18、段后9磅 |
| 二级标题 | 等线13磅，加粗、左对齐，无首行缩进，1.2倍行距；段前12、段后6磅 |
| 图片段落 | 居中、无首行缩进；段前6、段后3磅 |
| 图注 | 等线9.5磅，居中、无首行缩进，1.2倍行距；段前3、段后12磅 |
| 独立公式 | Cambria Math 12磅，优先可编辑公式，居中、无首行缩进；前后各8磅，使用自动行高 |
| 来源 | 等线9.5磅，左对齐、无首行缩进，1.2倍行距；段前0、段后6磅 |
| 表格正文 | 等线10.5磅，无首行缩进，1.2倍行距；段前0、段后3磅 |
| 代码 | Consolas 10.5磅，左对齐、无首行缩进，1.15倍行距；保留代码自身缩进 |

- 正文首行缩进使用Word原生字符缩进，不用空格或制表符模拟。标题、带标签的提示段、来源、图注、图片、独立公式、代码和表格显式取消正文首行缩进，避免继承错误；列表采用原生编号或项目符号及悬挂缩进。提示段沿用正文行距和段间距，代码自身缩进不受段落首行设置影响。
- 表格单元格上下内边距0.18厘米、左右0.2厘米，垂直居中；不设置可能截断文字的固定行高。表格后的正文或提示段使用专用样式设段前8磅，其余排版保持对应段落规则，不插空段制造间隔。表格及图片适配当前页边距内的可用宽度，不靠缩小文字塞入页面。

- 等线正文使用常规字重，标题加粗，不混用Light字体。对标题、正文、表格、图注、来源及适用的目录样式显式设置中西文字体，清除会覆盖这些设置的字体主题属性，并检查段落直接格式；不只核对字体名称。公式与代码保持各自字体，不因统一中文样式被覆盖。具备Word检查能力时核对标题与正文的实际字体，再结合渲染确认效果。
- 使用原生Word标题样式与对应大纲级别，支持导航窗格。排版后正文达到10页时增加可更新目录，收录一级、二级标题；正文页数不含目录及来源附录。较短笔记不强加目录，也不增加与正文重复的逐章摘要。
- 标题、正文和公式默认黑色；按主规则选出的重点一般局部加粗，少数最关键的短语或短句可用深蓝色 `#2F5496` 加粗，字号不变。全文只增加这一种强调色，不用彩色底纹、装饰框或多色分级；颜色仅辅助辨认，黑白打印时仍可通过加粗识别。默认标题不加装饰横线，检查并清除Title样式及标题段落中模板遗留的边框，不能只改字体颜色。不为塞入内容而缩小表格文字。公式与代码仍须完成语义核对，排版后检查关键符号与结构。
- 内容自然连续排版，用样式控制留白，不插入空段撑版，也不为维持原页数压缩字号、行距或删减内容。不强制每个知识点另起一页；标题与后文、图片与图注保持相连，简短引入、公式与必要解释尽量相连。长推导、长代码允许合理分页，不整块绑定制造大面积留白。渲染后检查拥挤、过度留白、标题落单、图注分离、公式裁切、表格溢出和空白页，优先调整布局，不删掉关键知识来凑页。

## 大文档整理与分批检查

- 大文档按章节分段整理，不反复重建全部正文。
- 渲染后每次只加载1—2页图片，分批检查全部页面，并持续说明已检查范围、发现的问题和剩余工作。不得一次返回大量页面图片，也不得以分批检查为由跳过页面。
- 首次渲染后，仅在实际修改后重新渲染相关文档；复用其他文档的有效结果。分批整理和检查用于减少重复处理与单次图片加载量，不保证绝不卡顿。
- 复用已检查的关键帧及页面，符号疑点优先查看清晰局部，不重复返回整页截图或全部文档正文。文档修改后复查实际受影响页面；若后续分页变化，继续检查相应后续页，不能只检查改动文字所在页。初次渲染仍须检查全部页面。

## Windows渲染接入

- 本机已安装LibreOffice，程序目录为 `C:\Program Files\LibreOffice\program`。仅适用于此Windows环境；路径或环境变化时重新核对必要项目。
- 继续使用当前 `documents` 技能的 `render_docx.py` 及内置Python、Poppler。该渲染器在Windows通过PATH查找 `soffice.exe`；只向本次渲染命令进程的PATH补入LibreOffice和已确认的Poppler目录，不修改系统或用户的永久环境变量，也不修改托管的渲染脚本。
- 下面变量分别表示当前技能与依赖信息确认的内置Python、渲染脚本、Poppler目录、输入文档及本任务 `work/` 内的检查目录；在独立的渲染命令进程中执行：

```powershell
$env:PATH = 'C:\Program Files\LibreOffice\program;' + $studyPopplerDir + ';' + $env:PATH
& $studyPython $studyRenderer $studyDocx --output_dir $studyRenderDir --dpi 150 --emit_pdf
```

- 首次接入先用一份含公式、矩阵、中文和表格的文档验证DOCX→PDF→页面图片；不能仅凭程序存在或退出码为零宣称视觉验收完成。
- PDF和页面图片用于内部检查，保存到本任务 `work/` 的分文档目录，默认仍只交付Word。若原生公式的特殊符号在当前引擎中显示异常，核对结构、采用语义等价的可编辑表示后重新渲染，不静默改动计算含义。
